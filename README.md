The make.fun ghost appears twice, both with a job in the document: as the
school's seal (top left) and as the principal signing the card (bottom left).

(1600×1600, crisp text, real press-kit ghost) — no AI-generated picture, so

`makefun-coin-keystone-star` in its text. `POST.json` names the post's

post itself from X and hands its first picture + text to the judge.

Files: `meme.png` — the meme as posted (1600×1600 PNG); `POST.json` — the X
post's address (placeholder until the post is live); `main.ts` — copies
POST.json to the output directory (Node 22, stdlib only); `LICENSE` — MIT.
